# SWYNEX Data Cleaning & Preparation

## Internship Task 1

### Project Overview
This project focuses on data cleaning and preparation using Python and Pandas as part of the SWYNEX Data Analyst Internship.

### Dataset
Student Performance in Exams Dataset.

### Tools Used
- Python
- Pandas
- Google Colab
- GitHub

### Data Cleaning Process
1. Loaded the original CSV dataset.
2. Checked for missing values.
3. Identified duplicate records.
4. Removed duplicate records.
5. Inspected column data types.
6. Exported the processed dataset to a new CSV file.

### Project Files
- `StudentsPerformance.csv` – Original dataset
- `Cleaned_StudentsPerformance.csv` – Processed dataset
- `SWYNEX_Data_Cleaning_.ipynb` – Python notebook

### Conclusion
This project demonstrates basic data cleaning and preparation techniques using Python and Pandas.
